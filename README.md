# Earth Character Studio

`earth-character-studio.html`을 브라우저에서 열면 바로 실행됩니다. React 18.3.1과 ReactDOM이 HTML 안에 포함되어 있어 서버, 설치, 인터넷 연결이 필요하지 않습니다. 입력한 리그 설정과 SVG는 외부로 전송하지 않습니다.

## 사용 순서

1. **감정 표현**에서 기본·기쁨·신남·슬픔·화남·놀람·졸림·윙크를 선택합니다. 감정 강도로 기본형과 감정형 사이를 조절합니다.
2. **리그** 탭에서 고개/몸 기울기, 시선, 눈 감기, 입 벌림을 조절합니다.
3. **회전 중심점**에서 파트를 선택하고 피벗 표시를 켠 뒤 캔버스를 누르거나 드래그합니다. 좌표를 숫자로 입력할 수도 있습니다.
4. **움직임** 탭에서 호흡, 몸/뒷머리 흔들림, 깜빡임, 말하기 데모를 설정합니다.
5. **전환** 탭에서 이징과 전환 시간을 조절합니다. 베지어 슬라이더를 변경하면 사용자 곡선으로 전환합니다. 설정은 다음 감정 전환부터 적용됩니다.
6. **기본 동작** 버튼으로 끄덕이기·도리도리·바운스·깜빡임을 실행합니다. 일시정지/동작 줄이기가 켜져 있으면 동작 버튼이 비활성화됩니다.
7. **리그 설정 저장**으로 JSON을 내려받고 **설정 불러오기**로 복원합니다. 자동 저장은 하지 않습니다. **현재 포즈 SVG**는 그 순간의 벡터 형태를 저장하며 애니메이션은 포함하지 않습니다.

탭을 다른 곳으로 전환하면 자동 일시정지합니다. 돌아와서 재생 버튼을 누르면 이어집니다.

## React에 연결하기

- `EarthCharacter.jsx`: 재사용할 React 컴포넌트와 런타임. React 18 기준.
- `ReactExample.jsx`: 컴포넌트 연결 예제.
- `earth_character.svg`: 제공된 SVG의 변경 없는 복사본.
- `studio.css`: 스튜디오와 캐릭터 크기 스타일. 앱에서는 `.earth-character` 관련 스타일만 분리해도 됩니다.

```jsx
import EarthCharacter, {DEFAULTS} from './EarthCharacter.jsx';
// Vite 사용 시:
import svgSource from './earth_character.svg?raw';

<EarthCharacter
  ref={characterRef}
  svgSource={svgSource}
  options={{...DEFAULTS, emotion:'happy', intensity:0.8}}
/>
```

캐릭터를 담는 부모 요소에 너비와 높이를 지정하세요. 전달하는 SVG는 이 패키지의 알려진 SVG 텍스트를 사용합니다. 런타임의 최소 구조 검사는 임의 외부 SVG를 안전하게 업로드하는 보안 샌드박스가 아닙니다.

주요 메서드:

```js
characterRef.current.transitionTo('wink', 0.8);
characterRef.current.play('nod'); // nod, shake, bounce, blink
characterRef.current.setSpeechLevel(0.6); // 0–1
characterRef.current.setSpeechLevel(0);   // 음성 종료 시
```

`options.emotion`을 React state로 제어할 때는 감정 변경도 그 state에 반영하세요. 명령형 API와 제어형 prop을 서로 다른 값으로 동시에 쓰지 마세요. 스튜디오에서는 `window.earthCharacter`로 같은 런타임에 접근할 수 있습니다.

## 리그 구조

| 파트 | 기본 피벗 | 처리 |
|---|---|---|
| 전체 흉상 | (209,410) | 몸 기울기·호흡·흔들림·바운스 |
| 머리 앞/뒤 조립체 | (209,317) | 같은 피벗으로 머리카락·장식·얼굴을 함께 이동 |
| 왼쪽 뒷머리 | (70,150) | 작은 독립 흔들림 |
| 오른쪽 뒷머리 | (350,150) | 작은 독립 흔들림 |
| 눈 흰자·동적 마스크 | 원본 눈 좌표 | 동일한 M L C C Z 구조의 정확한 좌표 계산 |
| 눈꺼풀 | 원본 눈 좌표 | 모든 감정에서 M C C C C Z |
| 입 | 원본 입 중심 (209,286) | 모든 감정에서 M C C Z |
| 홍채·하이라이트 | 눈별 한 그룹 | 함께 이동, 눈 경계 안에 클리핑 |

원본 SVG의 의미 ID, 색, 그라디언트를 보존합니다. 각 인스턴스에는 ID 접두어를 붙여 여러 캐릭터를 한 페이지에 표시할 때 클리핑/그라디언트 충돌을 피합니다. 공통 얼굴 노드는 감정 변경마다 교체하지 않습니다.

SVG Character Animator의 render-once, 현재 포즈에서 재전환, 공통 paint, 독립 idle 레이어 원칙을 적용했습니다. 감정 경로를 동일한 절대 좌표 명령 구조로 작성했으므로 generic morph나 flubber 의존성은 필요하지 않습니다. idle은 전환 시간의 40%에 걸쳐 sine 곡선으로 0.1까지 줄이고 전환 종료 후 복구합니다.

## 구현 범위

제공된 SVG는 팔·손이 없는 정면 흉상입니다. 이 파일에 없는 팔, 걷기, 옆모습을 새로 그리지 않았습니다. 기본 동작은 현재 그림의 머리·흉상·뒷머리로 표현합니다.

말하기 데모는 소리 없이 입을 움직이는 기능입니다. `setSpeechLevel()`은 외부 TTS/오디오 분석기 연결 지점이며, 음성 합성·마이크 녹음·음소별 viseme 분석은 포함하지 않습니다. 사용자가 준 범용 가이드의 모든 선택 기능을 구현한 것은 아닙니다.

원본 그림 파일과 가이드는 수정하지 않았습니다. 파생 표정은 원본에 없던 표정이므로 기본형을 바탕으로 새로 설계했습니다. 피벗을 멀리 이동하거나 여러 슬라이더를 극단값으로 조합하면 평면 그림의 목/몸 연결이 부자연스러워질 수 있습니다.
